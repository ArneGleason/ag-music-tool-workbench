use practical lighting and moonlight so the action and environment remain
readable while retaining the nocturnal mood. Apply this direction to future
scene references, generated clips and Blender lighting/compositing decisions.

The establishing environment is a remote monster zoo and biological laboratory
surrounded by swampland, with a possible coastal setting. The first environment
candidate includes an exterior helipad and a raised approach road. Those layout
details remain subject to reference approval. Preserve the gradual monster reveal.
